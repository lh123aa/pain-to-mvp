# P6第三轮A4稳定性：发现并修复#30假成功退出码+#31跨轮去重断链，清单回退生产实证

## 增量：A4 稳定性第 2 轮暴露双缺陷 → 当日 TDD 修复闭环（#30/#31）

### 决策
- **#31 修法**：crawl 落"本轮成功清单" `.crawl_manifest.json`，`collect_raw_files` 在 since 过滤为空时回退清单——仅当清单新鲜（mtime >= since）且所列文件存在；陈旧/损坏拒收。**不违反 #3 复用禁令**：清单是本轮 crawl 自己产出的范围凭证，不是上轮产物
- `crawl_one` 失败（robots 禁止/适配器异常）返回 None 不进清单——全失败轮不落清单 → 下游诚实断链（"失败假装成功"是 #28/#30/#31 同一族缺陷）
- `storage.jsonl_path_for` 置于 fix_storage 字节比对段**之外**（不动 overlay 一致性），路径公式等价性由测试锁定
- **004/005 同簇重跑副本不入校准记录**（防 n 灌水）：校准样本按"数据轮"记而非"稳定性轮"记；A5 第三轮 fresh 抽检以 003 为准
- 改 apply_fixes 覆盖文件（e2e）→ 新增 overlay `fix_e2e_exitcode`；改 copy_new_modules 拷贝的 run_inputs → 同步 `generators/fixes/`（幂等测试兜底，RK-0001 精神）

### 问题与解法
- **#30 假成功退出码**：`_report` 无返回值 + `main` 早退直接 return + `__main__` 不看结果 → discover 崩/数据缺失/步骤 ❌ 一律 exit 0。11:41 轮断链却 EXIT=0 是实锤。修：`_report(steps, total, expected=6)` 返回"步数 >= expected 且全步骤 ok"布尔，main 全路径传播，`__main__` 改 `raise SystemExit(0 if main(args) else 1)`（--skip-crawl 按 expected=5）
- **#31 跨轮去重断链**：#20 去重（10-15 引入）与 e2e/run_all 的 `since` 过滤的**组合缺陷**——同关键词重跑视频与既往重叠 → 写入 0 新 → 文件 mtime 不变 → since 过滤为空 → 误判"未找到评论数据"停链；网络实际正常（手动 crawl 拿到 104 条）。10-13 能连跑 3 次是因为当时还没有跨轮去重——回归是被 A4 稳定性测试揪出来的
