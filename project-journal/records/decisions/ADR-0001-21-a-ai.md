# #21 方向A收窄版：补证据驱动维度（竞争=对比+失望、AI杠杆=形态词表），触达留空

# 背景
评分仅 2/5 维参与均值：`competition/reach/ai_leverage` 恒为 None，报告标"未评"（OPEN_ISSUES #21，2026-10-14 报告追查发现）。

# 选项
- 方向 A（收窄版，我推荐）：补两个**能诚实测**的维度 —— `竞争空缺` = 簇内对比+失望信号启发式、`AI杠杆` = 代表句形态词表；`触达难度` 承认无独立数据来源留 None；排序必须拿真实数据回归验证 112 反超格局不被破坏。
- 方向 B（2 维制诚实收缩）：报告/卡片只标实际参与维，删"未评"假象 —— 零排序扰动，但竞争维度永远缺席。

# 决定
方向 A 收窄版（用户拍板 2026-10-15）。

# 理由
竞争维度是机会判断的核心（有竞品但不满意 = 空缺大）；数据已存在（`pain_rules` 已检出"对比/失望"簇级计数、代表句原文在手）属于"能诚实测"；方向 B 等于永久放弃该维度。

# 代价/风险
均值从 2 维变 3-4 维会移动分数分布（真实 112 簇 80.0 → 85.0 恰过 S 线）；小簇可能靠密度加成虚高（由 `_confidence_factor` 惩罚兜底，11 簇实测 59.6 B）。

# 证据
commit b229b7b + 1687931；全量 143 passed；真实三簇回归 85.0 S / 59.6 B / 43.7 C，112 反超保持，触达全员 None。

# 下一步
校准闭环（#11）用真实抽检验证新排序的命中率是否优于旧版 —— 这是"自己学会筛选"对本决策的最终检验。
