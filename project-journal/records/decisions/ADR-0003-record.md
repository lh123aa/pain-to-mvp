# 工作约定：每阶段完成必须展示全局进度看板

# 背景
用户 2026-10-15 提出工作约定：**每次一个阶段完成，必须展示完整全局进度**（总目标 + 各阶段状态看板 + 关键数字 + 风险 + 下一步），让全局可见，避免只看到最后一个 commit。

# 选项
- 只报本阶段增量（此前做法）
- 每阶段完成固定输出全局进度看板

# 决定
采用全局进度看板，此后每次阶段完成按统一格式汇报（阶段表 / 关键数字 / 未闭环 / 风险 / 下一步）。

# 理由
多阶段长项目中，增量汇报会让全局进度不可见；看板同时是止损线的观测器（"连续 2 周无阶段推进"需要看板才能客观判定）。

# 代价/风险
每次汇报多几十行 —— 可接受。

# 证据
本条即首份看板的产生场景（2026-10-15 #21 收尾时）；后续看板见各阶段收尾汇报与日记。

# 下一步
阶段状态变化时更新看板；看板阶段表与 OPEN_ISSUES 对齐。
