# P0 域校验选纯词表规则 + 阈值0.3→0.5（真实数据证伪后收紧）

# 背景
域校验（判断召回是否跑偏）需要在"纯词表规则"与"LLM 判定"之间选型；且重合度阈值需要定标。

# 选项
- 纯词表规则（三层防线：Layer1 关键词预检 / Layer2 成人擦边清洗 / Layer3 召回标题重合度）
- LLM 判定（更灵活但引入依赖与不可测性）

# 决定
1. 纯词表规则实现三层防线（2026-10-14，7893441 / cd56a5a）。
2. 重合度阈值 0.3 → 0.5（2026-10-14，2f7cdb3）。

# 理由
词表可测试、零依赖、行为可控；LLM 留作后续替代路径。阈值 0.3 是我先拍的，被真实数据**证伪**：1/3 命中判"基本一致"是误导；收紧到 0.5 后判定与文案一致，并加边界测试锁死。

# 代价/风险
词表需随新域维护；LLM 替代未做（留待校准闭环之后再议）。

# 证据
真实数据验证：娱乐域「女孩喜欢的物件」80% 判定、问题域「独立开发者怎么接单」93% 判定，文案一致、报告零 emoji（docs/exec-report-20261015-0929-* 已入档）；判定与文案不一致的问题由 8657ab7 修复并配测试。
