## 0. 评估基线：软件三件套（基础 · 功能性 · 结果）

> 先把「评估对象到底是什么」立清楚——后面所有判断都基于这三层事实。

### 0.1 基础（工程地基）【事实】

| 项 | 现状 |
|---|---|
| 规模 | 约 1.36 万行 Python（脚本+生成器）；46 commits / 8 天（2026-10-11 → 10-18） |
| 测试 | **238 项全绿**（外机克隆已独立复现，2026-10-19） |
| 工程纪律 | fail-close（robots 读不到即跳过平台）；**风控拦截从不假成功**——5 次生产实证「拦截即诚实失败（EXIT=1）」；不绕过验证码；数据本地不上云；作者名脱敏 |
| 可信机制 | 校准闭环：每轮抽检 top 卡片 → 记录真假 → 回看命中率 → 据信号级命中率调权（可回归） |
| 数据源 | B站（已生产验证）；YouTube/Reddit/小红书/抖音适配器在册（未深度验证） |
| 形态 | Windows 本地 CLI + localhost 只读看板；单用户 |
| 维护模式 | 生成器 + overlay 双轨（改动需多文件同步，是效率债；但对可复现性有利） |
| 短板 | 单平台依赖（无备用数据源）；无云端；单用户；无流量 |

### 0.2 功能性（能力清单）【事实】

```
关键词（模糊输入）
  → 关键词扩展 + 平台选择
  → 内容发现（≤20 条候选，失败绝不复用旧产物）
  → 评论爬取（≤500 条；跨轮去重；robots fail-close；≤1 req/s）
  → 痛点挖掘（规则信号 7 类；BERTopic 主 / TF-IDF+KMeans 兜底；噪音过滤；多样性防复读）
  → 机会评分（证据驱动 5 维；无证据的维度留空不硬凑；LLM 可选且单轮上限 ¥2 / 启发式兜底）
  → MVP 设计（六卡框架 + 收入三层：咨询→模板→社群）
  → 输出：机会卡(md) + 执行报告(md/html) + 看板(3s 轮询)
```

**差异化功能点**：执行报告六节可核对（决策漏斗 / 分数拆解 / 被过滤评论逐条理由 / 域自查 / 异常 / 规则表）——**每个结论可反推回原始评论**；产物按项目归档；校准记录可审计。

**论点**：群体存在且活跃——间接证据充分；但本项目与它的连接度为 0。

### 证据【事实·公开对标】

|---|---|
| 海外付费实证 | GummySearch 曾有 **1 万+ 付费用户**（报道口径 ~$35K MRR）——「愿意为找需求付钱的开发者」真实存在 |

| 内容侧热度 | 「立项调研/BRD 」类文章与流水线在独立开发者圈持续出现（腾讯云社区 2026-04、tcti.cn 2026-04 等） |

- 国内独立开发者/准独立人群 ≈ **10–30 万人**（假设：软件从业者百万级 × 1–3% 独立倾向；误差 ±3 倍）；
- 其中「会为需求验证付费」的人数**无数据**——海外证明存在，国内未验证。

### 打分与结论

| 维度 | 打分 |
|---|---|
| 群体存在性 | **8/10**（无需再验证是否"有人"） |
| 项目与该群体的连接度 | **0/10**（从未与任何外部用户对话） |
| **综合** | **7/10** —— 群体真实、活跃；项目瞄准的是其中「已动手、卡方向」的子集（最可能付费的切片），方向选得对，**就差走出门** |

## 2. Q2：需求是否真实存在？

### 先做一个关键澄清【判断】

**本项目能挖出「别人的痛点」，不等于「本项目自己的需求」存在。** 两者必须分开验证：

- 前者（管线能否找到真痛点）——**已有实证**：112 条证据卡、S 档、抽检 top3 达 66.7%（接近成功线）。
- 后者（有人愿意为「自动找需求」付钱）——证据如下，分层判定。

### 需求三层拆解【判断】

| 层 | 需求表述 | 真实性证据 | 判定 |
|---|---|---|---|
| A | 「不知道做什么 / 拿不准值不值得做」 | B站评论自然涌现、BRD 类内容热度、开源项目涌现（自建工具=需求信号）、项目自身动机 | **真实存在**（行为证据充分） |
| B | 「想用工具/服务来解决它」 | 免费库被建、海外付费工具 1 万+ 用户、国内免费工具被使用 | **存在**（海外已证明付费；国内付费未证明） |
| C | 「为本项目付钱」 | 无任何一手证据（0 对话、0 成交、0 付费信号） | **未验证——唯一的真未知数** |

### 诚实列入的反面证据【事实】

- **免费替代充足**（ideaSearch / Indie Hunter / 开源克隆）→ 付费动机被稀释；
- 「习惯性抱怨者」现象（博客园既有观察）——愿意抱怨、不愿付费；
- 国内独立开发者付费习惯呈两极：**愿为课程/社群付费**（已验证），**愿为自用工具订阅付费弱**（缺国内个体数据）。

### 打分与结论

| 维度 | 打分 |
|---|---|
| 需求真实性（A 层） | 9/10 |
| 付费需求成立度（B/C 层） | 5/10 |
| **综合** | **7/10** —— 「找方向」是真需求、真痛点；「为本工具付费」是待验证假设（项目自己的 CHARTER §3 也标注 `待确认`，诚实一致） |

## 3. Q3：能不能够做到变现？

### 模式 × 条件表【判断】

| 模式 | 现在能不能 | 缺什么条件 | 现成弹药 |
|---|---|---|---|
| **服务单（定制报告/代做）** | ✅ **能试**（风控解锁即可，人工跑批交付） | 风控解锁 | 话术 3 版 + 深度交付物 + 价格带对标（¥199–999） |
| 单份报告售卖 | ⚠️ 待达标 | 校准 ≥70% + 分发启动 | 4 份报告已备 |
| 工具订阅 SaaS | ❌ 当前不成立 | 风控 + 合规 + 成本 + 流量**四重卡点** | 网页化评估已详析 |
| 工具授权/自部署 | ⚠️ 中期可 | 打包/防破解/支持 | 未开发 |
| 社群/内容 | ⚠️ 慢但稳 | 持续输出 | 报告素材即内容 |

### 前置三件套（当前全缺）【事实】

1. **风控解锁**——5 次拦截，等 IP 冷却/换网络出口（今晨是预定重试点）；
2. **可信达标**——66.7% < 70%，差最后 12 条校准；
3. **分发启动**——0 曝光、0 发布。

### 时间与金额的合理预期【估算】

- 最快首单：**风控解锁后 1–4 周**（熟人社群直发，话术已备）；
- 首年（基准）：月 1–8 单 × ¥199–499 ≈ **年 ¥0.5–4 万**；加社群/报告零头。

### 打分与结论

**6/10** —— 「能不能变现」的答案是**能（服务化路径真实存在且弹药已备 90%）**；但「变现成规模」当前**不成立**——三件套未解之前，一切收入推演都是纸面的。变现的关键动作不是写代码，而是：解锁风控 → 补齐校准 → 发第一份报告 → 收第一单。

### 4.2 对本项目的映射【估算】

| 情景（12 个月） | 收入区间 | 前提 |
|---|---|---|
| 保守（仅服务化） | ¥0.5–2 万/年 | 风控断续、月 1–3 单 |

**重要警示【判断】**：**不要用 GummySearch 的 $35K MRR 对标本项目**——它同时占了三样本项目没有的东西：10 倍大的英文市场、平台（曾）允许的商业 API、先发 5 年的品牌。把它的数字当激励 = 自欺。

### 4.3 资产转手价值【判断·常见口径】

- **现在**：≈¥0（0 收入；数据资产绑定单平台、不可自由转移）；
- 若跑出稳定月利润 ¥3K：微收购市场常见估值 = 年利润 × 1.5–3 ≈ ¥5–10 万——但本形态（单人服务+平台依赖）**找到买家的概率低**；
- 代码本身：开源即公开 ≈ ¥0。

### 4.4 另一种「参考价值」：方法论案例价值【判断】

「证据链 + 校准闭环 + fail-close 不骗人」的工程方法论本身有内容价值——可写成"如何做一个不骗人的 AI 分析工具"系列（B站/知乎/即刻），与独立开发圈调性匹配。变现上限小（换信任与线索），但零成本、与主线协同。

### 打分

**4/10** —— 收入中位数（¥1–6 万/年）真实但不性感；资产转手 ≈0；唯一值钱的是"跑出来的案例与信任"，且要靠执行兑现。

### 最终判断（一段话）

**这个软件的变现价值：作为「软件产品」≈ 低（无护城河、无流量、单平台、0 外部验证）；作为「服务 + 内容 + 工具」的组合 ≈ 中等且真实（弹药 90% 备好、需求群体与付费带都有实证对标）。**
价值不在代码里，在**三件套的解锁顺序**里：**风控解锁 → 校准达标 → 第一份公开发布 → 第一单成交**。跑通首单之前，「值多少钱」没有意义；跑通之后，参考水位是「月几百到小几千、年 ¥1–6 万（中位）」，上不封顶的前提是多平台+合规+流量——那是另一个量级的工程与风险。

### 与既有评估的一致性

- 与 `VALUE-ASSESSMENT.md`（2026-10-18）结论方向一致：不直接卖订阅、先服务化、追首单而非追估值；
- 与 `WEB-MONETIZATION-ASSESSMENT.md`（2026-10-19）一致：网页是门面不是收入主体；
- 本五问版的任务是**把「价值有多高」拆到用户/需求/变现/对标/竞争五个确定维度上**，结论：**中等偏下（5.7/10），但下限真实**。
