# 校准公示：评分器的成绩单，我们公开

> 快照日期：2026-10-19 ｜ 数据源：项目校准记录（逐条可核对）
> 一句话：工具只给结论、不给成绩单是常态；我们把成绩单贴出来——未达标也贴。

## 1. 什么是校准（为什么它稀缺）

- 大多数「找需求 / 机会评分」工具输出机会清单，却从不回答一句话：你上次说的机会，是真的吗？
- 本项目的闭环：每轮跑完 → 抽检 top 卡片 → 人工判定「真 / 假」→ 记录归档 → 满 20 条回看命中率 → 调整规则。
- 判定必须写理由（**空理由拒收**）；同一张卡不允许重复记录（**防刷分**）——机制层面拒绝造假。
- 校准不是承诺「全对」，而是承诺「每个结论都被回查过，且成绩单公开」。

## 3. 校准轨迹（事实）

- top3 口径随时间：33%（5 条时点）→ 60%（7 条）→ **66.7%（8 条）**——随样本增加收敛中。
- 里程碑：卡 003（落地页预算型机会）在 fresh 数据轮被判「真」且排名第 1。
- 信号级初窥（20 条完整回看前的候选线索）：求助、期望两个信号命中率 67%，为优先调权候选。

---

## 4. 防灌水与纪律（机制细节）

- 记录字段：日期 / 卡号 / 判定 / 理由（必填）/ 轮次 / 排名 / 原话可否回溯 / 信号分布。
- fail-close 三道闸：非法判定拒收；空理由拒收；同卡重复拒收。
- 稳定性重跑产生的同簇副本**不计入**校准（防止同一发现刷两次分）。
- 达标线不因样本不足下调：top3 ≥70% 是事前定好的线，未达标就是未达标。

---

## 5. 达标后的安排

- 满 20 条：逐信号回看命中率 → 调整信号权重 → 重跑验证（轨迹继续公示）。
- top3 稳定 ≥70% 后：作为可信度资产用于报告与页面展示（当前不以此做任何承诺）。
