# 定价验证 · 以同类产品对照重新定价

> 日期：2026-10-19 ｜ 性质：独立分析（价格=待验证假设，非承诺）
> 上游：`VALUE-ENHANCEMENT-PORTFOLIO.md`（补 4 报告分级）｜ 口径来源：`WEB-MONETIZATION-ASSESSMENT.md`、`MONETIZATION-5Q-ASSESSMENT.md`、`VALUE-ASSESSMENT.md`、`first-order-outreach-scripts.md`

> 标注：**【事实】**（公开快照/项目记录）｜**【判断】**｜**【估算】**（含汇率折算 ~7.2）。

## 0. 直接回答

**"确定"不能这么叫——价格不存在"确定"，只存在"有依据"与"待实测"两层：**

1. **有依据的部分（结论：站得住）**：`¥199–499` 这个**区间**同时被三条锚支撑（国际自动报告带的上方、国内知识服务带的内侧、项目自身已对外口径"200–500"）；**【判断】**
2. **待实测的部分（结论：不能确定）** ：单点价格（199/499/999）是**建议价**，最终价必须由首单真实成交校准——这正是项目既定纪律（CHARTER §3："探测付费意愿后再定价"；MONETIZATION-EXECUTION 阶段 3 触发条件）；
3. **风险已被设计吸收**：先用**首单验证价 ¥199**（=深度版内容，限前 3–5 单）把"定价风险"压缩成一次小额实测，成交价记入 ledger，5 单后复盘修正。

> 一句话：**区间是有证据的，单点价是要试出来的；现在能"确定"的是定价机制（见 §4），不是具体数字。**

## 2. 定价推导（三条锚 + 一条地板）【判断】

1. **自下锚（国际自动报告带 ¥36–210）**：本项目交付物 = 自动管线产出 **+ 人工复核/定制 + 证据链可回溯 + 校准自证** → 应站在该带**上沿**，不能更便宜（更便宜=自贬，且低于成本）；
2. **自上锚（国内企业报告带 ¥999+）**：无合规通道、无品牌、无 B 端案例 → **够不到**这带上沿；但白标档可搭其下沿（¥999 起）；
3. **内侧锚（国内知识服务带 ¥99–999）**：这是本项目最真实的参照系（目标用户=会为课程/社群/咨询付费的独立开发者）——**¥199–499 正好落在这带中部**；
4. **成本地板【估算】**：单次扫描全程成本 ≈¥25–125（WEB 评估口径）+ 人工在环 2–6 小时 → **常规零售价不低于 ¥199**；低于 ¥199 成交需在 ledger 记录理由（验证单/案例单除外）。

**结论**：`¥199（基础）/ ¥499（深度）/ ¥999+（白标）` 是**三条锚同时支撑的结果**——上不悬空、下不亏本、外有同类参照。**区间成立；单点待实测。**

## 4. 首单验证机制（定价怎么被"试"出来）

| 步骤 | 动作 | 记录 |
|---|---|---|
| 1 | 首单用 **¥199 验证价**（限前 3–5 单），显式说明"验证价，后续恢复 ¥499" | 成交价写 ledger（收入线首笔） |
| 2 | 每 5 单复盘一次：成交价 vs 报价、还价幅度、流失原因 | journal 追加 |
| 3 | 调整规则：≥3 单"嫌贵流失" → 降档或拆小权益；连续 3 单不还价 → 试探上探（¥399/¥599） | 变更需在 CHARTER §4 记录理由 |
| 4 | 复核点：首单后 30 天做第一次正式定价复审 | metrics 记录 |

**禁止项**：不编成交数据；不"先涨价再打折"制造假锚；未达标（校准/风控）前不做任何公开发布报价承诺。

## 5. 风险与边界（诚实交代）

- **无完全同类**：中文评论区 + 证据链 + 校准自证的定制报告，国内外均无直接对标 → 只能"区间锚定"，不能"照抄对标价"；**【判断】**
- **个体付费习惯**：国内独立开发者"愿为课程/社群付费"已验证，"愿为工具/报告付费"未验证（5Q 评估 Q2）→ 首单优先熟人/群，验证价开路；
- **两个价格实验不要混**：验证价（探测）≠ 正式价（常态化）；**验证价必须显式标注**，否则会污染价格锚；
- **汇率折算**：【估算】~7.2，非精确比价；国际产品近年因 API 成本普遍提价，历史价（GummySearch）仅作信心锚不作对标价。
