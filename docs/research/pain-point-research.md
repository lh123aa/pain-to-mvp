# 痛点研究：什么是痛点、痛点发布在哪（2026-10-15）

> 背景：#11 校准讨论中，用户判定 112 条评论"对项目没有价值 = 不靠谱"，并要求先研究
> "什么是痛点、人们在哪里发布痛点"，再修系统的判断方向与标准。
> 本文事实附来源；标注（判断）的是我的综合推断，供讨论，不代表定论。

## 一、什么是痛点

### 1. 定义

- **痛点是事实，需求是观点**：痛点 = 具体场景 + 具体的人 + 具体被卡住的问题；
  "我想要个 XX 工具"是人对痛点的主观解读（来源：搜狐《痛点和需求，这次彻底搞清楚》）。
- JTBD（完成任务）视角：痛点 = 人想完成一件事的过程中的阻碍；
  NN/g 把它分为三层——单次交互层、整段使用旅程层、与商家关系层
  （来源：nngroup.com/articles/pain-points）。
- 可操作的标准句式：「在什么场景下，谁想完成什么，但做不到 / 代价太大」。

### 2. 真伪判据（业界硬标准）

- **唯一硬标准：用脚投票——愿不愿意付真实成本**（钱、时间、改变习惯）。
  嘴上说想要、却不行动 = 伪需求（来源：CSDN《真痛点？伪需求？》等多源同旨）。
- 痛感强度四问：痛不痛 / 多久痛一次（频次）/ 痛多久（持续）/ 多少人一起痛（广度）
  （来源：敏捷开发《如何洞察用户的真实需求》）。
- 痛点与需求辨析：痛点基于场景客观存在，需求是人的主观判断；
  识别伪需求的方法核心是验证"是否有人为此付出"（来源：avtechcn 辨析指南）。

### 3. 对本项目的含义（判断）

- 现有 pain_rules 六信号（求助/抱怨/对比/失望/期望/付费意愿）**等权计数**，
  情绪类信号与成本类信号同分——"喊疼的人"和"真掏钱的人"在分数里一样重，
  与"真实成本才是硬标准"相悖。
- 段子、玩梗、广告、闲聊属于**零成本内容**，天然无痛点价值，机器可判。
- 112 簇实测：能支撑卡片的评论只有 2/112，根因之一就是分数没抓"成本"主轴。

## 二、人们把痛点发布在哪（渠道可信度分级）

### 第一梯队：高可信（发帖本身要付出成本）

| 渠道 | 为什么可信 |
|---|---|
| 求助提问帖：知乎提问、贴吧、豆瓣小组、V2EX、Reddit、IndieHackers | 提问自带"场景+卡点+想要答案"三要素；愿意把问题写清楚 = 已付时间成本。海外创业者圈公认 Reddit 挖痛点是金矿（Inc.、painonsocial 多源） |
| 投诉平台：黑猫投诉、12315、电诉宝、消费保 | 实名 + 花精力 + 指向具体商家产品 = 最强"失望"信号；黑猫（新浪旗下）企业 24 小时响应、红黑榜透明 |
| 应用商店差评：App Store、华为应用市场等 | 对具体产品、具体版本开火；阿里云有专门聚合应用市场评论的产品，说明企业当真 |

### 第二梯队：中可信，量大但稀（**当前数据源在此**）

| 渠道 | 特征 |
|---|---|
| B站 / YouTube 视频评论区 | 量大但稀：112 条里仅 2 条支撑卡片（2026-10-14 实测）；域太宽易混入闲聊广告 |
| 微博、即刻、小红书体验贴、科技自媒体评论区 | 吐槽浓度高，但软广混杂 |
| 什么值得买 | 消费决策真实，但积分激励导致灌水 |

### 第三梯队：被刷脏（用户"商城评论不可参考"的判断获研究背书）

- 电商商品评论（淘宝/拼多多/京东/亚马逊）：刷单 + 好评返现是成熟产业链；
  学术界自 2013 年（Jindal 等）起持续研究虚假评论识别
  （来源：电子科大《虚假评论的识别与过滤：现状与展望》）。
- 淘宝 2020 年曾把中差评**合并展示**——平台还会藏差评（来源：新浪财经实测报道）。
- 新华网报道引学者：虚假好评系统性瓦解用户信任（来源：新华网）。
- 刷评破绽（识别信号）：模板化短评重复、集中扎堆出现、星级分布异常、
  "好评返现"话术、账号行为异常。

### 结论：可信度排序

**求助提问 > 投诉 / 差评 > 社交吐槽 > 商品评价**

## 三、对 pain-to-mvp 的启示（判断，待方向确认）

1. **数据源**：B站评论区是第二梯队，可留作补充；主矿应转向第一梯队的"求助提问帖"
   （知乎提问天然就是场景+卡点+答案期待）。
2. **判分主轴**：从"词表信号计数"转为"发这条的人付了什么成本"
   （花时间写清楚问题 / 愿意花钱 / 被实际挡住事）。
3. **零成本防线**：段子、广告、闲聊应机器过滤（现有 Layer 1 覆盖了部分广告，
   未覆盖段子与闲聊）。
4. **#11 校准判据**与本研究衔接：先判"评论对点子有没有价值"，
   价值的定义 = 有人付过真实成本。
