# 变现执行计划（零费用口径）· pain-to-mvp

> 状态：初版（2026-10-18）· 承接 `docs/MONETIZATION.md`（策略）与 `project-journal/CHARTER.md`（成功线/止损线）
> 硬约束：**不投入任何费用**（无投流、无服务器费、无付费渠道）；成本只允许"已有的免费阵地 + 时间 + 管线跑批"。
> 裁决权：商业判断在用户；本文只给"零费用口径下最快、最低风险"的一条闭环，附每阶段验收标准与止损点。

## 0. 现状盘点（事实，来源见脚注）

- 工具可信度：校准 **8/20**，top3 命中率 **66.7%**（成功线 ≥70%）[^cal]
- 可售物：机会卡 S 档 1（20261016-001，112 证据）+ 看板 18 需求；已有 112 簇全量评论重建稿 ^[review]
- 合规：B 站爬取合规红线已写入代码/测试；**当前被 v_voucher 风控拦截（生产实证 4 次，24h 冷却假设已证伪）** ^[pb0001]
- 收入：收支账本 0 行；CHARTER 收入线未定（售卖阶段另行补写）

**零费用口径的核心矛盾**：变现 = 有人为结果付钱。"产出物"已有（卡 + 报告），"让目标用户知道并愿意付钱"这一步在零费用下**唯一能走的是免费分发 + 信任转化**，不能走投流。因此闭环设计成：**先把工具证明可信（阶段 0，零费）→ 把可信结果做成免费公开报告换取信任与线索（阶段 1–2，零费）→ 用首单收钱验证付费意愿（阶段 3，零费）**。

| 1.2 | 每份报告出**单文件 HTML**（`scripts/dashboard` 范式，可离线打开） | AI | 每份 1 个 `.html`，能直接转发 |

## 与 CHARTER 的衔接

- 成功线（20 条 + top3 ≥70%）→ 阶段 0 达成
- 止损线（连续 2 周无阶段推进）→ 每阶段验收点即"阶段推进"证据，避免触发
- 收入线 → 阶段 3 首单后补写
- 合规红线（v_voucher 不绕过）→ 阶段 0 全程遵守，只等冷却/扫码，不做绕过

## 关键风险（零费用口径下）

1. **风控单点**：B 站接口持续收紧则数据源失效 → 阶段 0 卡死。缓解：优先扫码配 BILI_SESSDATA（登录态可显著降低风控），不等自然冷却。
2. **免费渠道零触达**：内容发出去无人看 → 阶段 2 止损点（7 天 0 反馈即换渠道/转直客），不追加费用。
3. **校准不收敛**：阶段 0 满 20 条仍 <70% → 触发止损复盘，不硬进售卖（守住"不许骗人"）。
