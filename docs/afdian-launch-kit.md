## 8. 发布合规 · 链接规则（2026-10-20 补）

**已发内容合规状态**：2 条动态 = 纯文字 + 图片，**零外链** → 不触碰任何平台链接类规则 ✅

**逐平台策略（后发内容遵守）**：

| 平台 | 链接规则【判断｜发布前复核】 | 我们的打法 |
|---|---|---|
| 爱发电（动态/商品） | 用户协议未禁止外链（2026-10-20 粗核约 7KB 协议全文，无「链接」限制条款）；但硬广式外链不得体 | 承接统一用**站内私信**；动态正文不放第三方链接 |
| B站（专栏） | 外链可放但可能进审核/限流；忌短链、二维码、诱导加群 | 正文放证据与要点；**文末最多 1 个链接**（推荐 GitHub 报告页） |
| 知乎（回答） | 外链有折叠/限流机制（尤其推广性质） | 优先**不加外链**：正文直接给结论 + 证据截图；最多文末 1 链且与内容强相关 |
| GitHub（README） | 无限制 | 自由挂链 |

**通用三原则**：① 正文先给价值，链接只做"延伸阅读"、最多 1 条；② 不用短链/跳转链/二维码刷屏；③ **每个平台发布前，先核对当时规则**并写进当次 checklist（不服役记忆）。
