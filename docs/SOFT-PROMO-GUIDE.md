# 软传播写作规范（防封禁版）

> 2026-10-20 用户指令：**任何发布先过平台规则；文章要"软"，不放明链（明链/二维码/价格一律不进正文）。**
> 适用：B站专栏、知乎回答、爱发电动态/商品描述、GitHub README 之外的一切公开内容。

---

## 0. 三不原则（硬红线，任何平台不破例）

1. **零明链**：正文不出现 URL、短链、二维码、微信号、QQ 群号、"加我/扫码"
2. **零价格 / 零售卖**：不出现 ¥、价格、"付费/购买/下单/接单/私信报价"
3. **零诱导**：不写"关注领取/点赞解锁/转发抽奖"；不承诺收益（"月入过万""稳赚"类）

---

## 1. 软传播的骨架（价值 > 品牌）

- 文章必须**独立成立**：读者一个链接都不点，也能拿走完整方法
- 品牌/产品出现次数 **≤1**，且只在结尾（"我整理了一份清单"）
- CTA 只做"轻接触"：**评论区聊 / 私信我**（平台内闭环，不导流）
- 用"局限 / 失败记录"换信任——比吹成绩安全，也更像真人
- 数字必须能回溯到报告；【事实】和【判断】分开写

---

## 2. 平台差异（发布前逐条复核当时规则）

| 平台 | 外链 | 承接方式 | 额外注意 |
|---|---|---|---|
| B站专栏 | 正文**不放**（简介/签名可放，【判断】） | 私信 / 评论区 | 不提"爬虫/抓取/风控"；不贬低其他 UP；分区选对 |
| 知乎回答 | 正文**零链接**（外链易折叠/限流） | 私信 | 不写"广告/推广"字样；回答必须与问题强相关 |
| 爱发电动态 | 正文不放第三方链接 | **站内私信** | 动态不写外部联系方式 |
| GitHub README | 无限制 | README 链接 | — |

## 3. 事实口径（写文章只能引用这些数字）

- 样本：**173 条 = 112 + 21 + 9 + 31**（4 份报告）
- 付费意愿（WTP）：001 10/112（9%）｜002 1/21（5%）｜003 3/9（33%）｜004 2/31（6%）
- 信号分布：001 求助 51%｜002 求助 71%｜003 求助 56%｜004 求助 68%
- 校准：**8/20 条命中 · top3 66.7%（未达 70% 成功线）**——文章里必须如实写"未达标"
- 禁止编造：市场规模、竞品收入、用户数等任何不可回溯数字

---

## 4. 发布前自检（10 条，全过才发）

1. 正文 0 个 URL / 二维码 / 微信号？
2. 0 个价格 / "付费/购买/接单"字样？
3. 品牌提及 ≤1 次且在结尾？
4. CTA 只有"评论/私信"？
5. 所有数字能回溯到报告？
6. "局限/失败"至少写了 1 条？
7. 没有绝对化用语（最/第一/保证/稳赚）？
8. 没有贬低竞品或其他创作者？
9. 与同账号近 7 天内容不重复；跨平台改写 ≥30%？
10. 该平台当日规则已复核（链接/引流/敏感词）？

---

## 5. 频率与节奏（【判断】）

- 同账号：**7 天内 ≤1 篇带 CTA 的内容**；先发 2 篇纯干货（0 CTA），再发 1 篇带软 CTA
- 发布后 24h 只回评论，不追发；数据不好不连发补救
- 跨平台必须改写（≥30%），避免被判搬运

---

## 6. 违规应急

- **被限流**：不删重发（间隔 ≥48h），先自查敏感词；记录到 journal
- **被判广告**：该平台停 2 周，只发纯干货恢复权重
- **被封**：不换号硬发；记录原因，转向其他渠道（阶段 2 本来就有多渠道路线）
