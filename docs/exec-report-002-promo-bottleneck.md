# 机会报告：「产品做出来了，不知道怎么推广」——独立开发者 21 条卡点

> 来源：B 站评论区 21 条真实评论聚合 · 机会卡 #20261013-002 · 生成时间 2026-10-18

## 一句话结论

**独立开发者最大的「隐性成本」不是写代码，而是「推广 + 获客」。B 站评论区 21 条里，求助 15 条（71%）集中在「产品没人用、不知道怎么推、找不到用户」上——这是产品做完后的第二道坎，几乎每个独立开发者都会撞上。**

**代表原话（匿名，来自 B 站评论区）：**

- 「独立开发，我感觉最难的就是如何推广自己的产品了，写出来的软件没有人用，很头疼啊。」
- 「哪有那么容易，有些行业业务复杂得很，连专注该行业软件公司开发的软件都远远不符合需求。」
- 「求推荐一个好用的落地页模板，太贵了买不起。」（关联卡 #20261011-001，9 条）

**关键洞察：**「推广难」不是单个视频的问题，而是跨视频、跨主题反复出现——说明这是独立开发者**普遍的第二瓶颈**（第一瓶颈是「做什么」，第二瓶颈是「推给谁」）。

## 切入角度

「推广难」太宽泛，MVP 需要**收窄到一个具体场景**：

- 场景 A：独立开发者做完了工具/SaaS，**落地页 + SEO + 首篇发布** 3 件事打包
- 场景 B：已有产品，**冷启动 100 个目标用户** 的方法论 + 工具包
- 场景 C：针对「菜农/本地商家」类垂直行业的**本地获客**（超市菜价卡，21 条）

**建议从场景 A 切入**：落地页 + 首篇发布（金数据表单 + GitHub Pages 零成本，交付物可复用）。

## MVP 验证路径（7 天，¥0–500）

| 天 | 动作 | 成功标志 |
|---|---|---|
| Day 1 | 找 10 个「有产品但不会推广」的独立开发者 | 建群 10 人 |
| Day 2 | 访谈 3 人，确认落地页/首篇发布是最大卡点 | 文字稿 |
| Day 3 | 做出 1 套「落地页模板 + 发布清单」HTML 交付物 | 可交付 demo |
| Day 4 | 尝试收 100 元（爱发电/微信） | 首单成交 |
| Day 5 | 交付 + 收集反馈 | ≥3 条书面反馈 |
| Day 6–7 | 复盘：继续/放弃/改方向 | 书面记录 |

**技术栈（零成本）：** GitHub Pages + 单文件 HTML + 爱发电 + 金数据
