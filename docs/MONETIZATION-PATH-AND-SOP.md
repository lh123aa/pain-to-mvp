## 1. 我们在卖什么

### 1.1 一句话定位

> **不是给你点子，是给你证据。**
> 帮你用公开评论区的真实原话，判断一个方向值不值得做。

### 1.2 产品阶梯（价格唯一口径：`docs/PRICING-VALIDATION.md`）

| 层级 | 价格 | 交付物 | 作用 |
|---|---|---|---|
| 免费公开报告 | ¥0 | 4 份机会报告（md/html/PDF）：信号分布 + 代表原话 + 评分 + 切入方向 + SOP 概要 | 获客、建立信任 |
| 免费打标清单 | ¥0 | 7 类信号 / 三密度指标 / 30 分钟流程 / 打标模板 | 私信承接的第一步价值物 |
| 免费数据探测 | ¥0 | 针对对方方向查 30 条评论，给 2–3 条原话；样本 <10 条直说做不了 | 证明「我真的会看数据」 |
| **首单验证价** | **¥199** | **前 3 单：按 ¥199 交付深度版内容**；条件：真实反馈 + 匿名案例授权 | 把定价风险压到一次小额实测 |
| 基础定制版（3 单后） | ¥199 | 定制关键词：完整证据链 + 评分拆解 + WTP 模块 + 缺口映射 | 常规零售入门 |

| 白标 / B 端版 | ¥999–2999 起 | 多关键词 + 品牌定制 + 导出包 + 1 次线上答疑 | 后期 B 端 |
| 订阅 / 机会简报 | 冻结 | 候选 ¥49–99/月 | 趋势能力上线 + 首单验证后再议 |

**首单承诺**：报告里少于 3 条可执行信号 → 全额退款。交付周期 3–5 天，HTML + Markdown，每条结论挂原始评论原话。

### 1.3 不卖什么

- 不卖「保证赚钱」「保证做出来」；只保证证据真实、可核对、判断有依据。
- 不卖大盘市场报告、B 端复杂采购、没有评论区的品类（做不了直说）。
- 不在公开区报价；报价只发生在私信，且对方已给出方向、看过样本之后。
- 不做「先涨价再打折」的假锚；不编成交数据。

## 2. 卖给谁（ICP）

| 优先级 | 人群 | 特征 | 常在哪 | 触发时刻 |
|---|---|---|---|---|
| P0 | 有技术、想做副业/独立产品的开发者 | 后端/全栈，能写代码，缺方向与验证 | B站、知乎、V2EX、即刻 | 「做出来没人用」「不知道怎么推广」 |
| P1 | 产品经理 / 独立创业者 | 有想法，怕做错，需要证据说服自己/老板 | 知乎、小红书、公众号 | 「需求调研怎么做」「怎么判断真需求」 |
| P2 | 自媒体 / 内容创业者 | 需要选题与差异化，愿为信息差付费 | 小红书、公众号、知乎 | 「评论区里找选题」 |

**他们最痛的三件事**：
1. 不知道做什么，怕又白做半年。
2. 做出来没人用，不知道怎么验证。
3. 评论太多、榜单太虚，看不完也看不懂。

**我们的切入**：不增加焦虑，只把他**已经感觉到但说不清**的东西，用原话和数据说清楚——让他觉得「这说的就是我」。

## 3. 变现路径（阶段 0–3）

### 3.0 漏斗

```
免费内容 / 评论（痛点共鸣）
  → 评论区 / 私信（说一句你的方向）
  → 免费资料（打标清单 / 4 份报告）
  → 免费数据探测（查 30 条评论，给 3 条原话）
  → 私信报价 ¥199（限 3 单，退款承诺）
  → 交付 → 案例授权 → 匿名案例卡
```

### 3.1 阶段 0 · 解锁可信（当前 ⛔ 40%）

**为什么最前**：校准不达标就卖报告 = 拿不够可信的结论换信任，违反「不许骗人」底线。

| 动作 | Owner | 验收 |
|---|---|---|
| 补满 20 条校准样本（B站风控冷却 / 原机 IP / 换出口后） | 用户 + AI | 20/20 |
| 首次回看：求助/期望两个低命中信号是否调权 | AI | top3 ≥70%，或明确「不调权」的裁决记录 |
| 校准页更新 | AI | 公开数字与 journal 一致 |

**止损**：满 20 条后 top3 仍 <70% 且调权不收敛 → 触发 CHARTER §5 止损复盘，不硬推售卖。

**红线**：平台 IP 级风控未解除（已多次验证）**不绕**；不碰任何绕过方案；等冷却/换出口/原机重试。

### 3.2 阶段 1 · 免费公开报告（当前 ◐ 90%）

| 动作 | Owner | 验收 |
|---|---|---|
| 4 份公开报告（md/html/PDF） | AI | 每份含痛点/证据条数/代表原话/评分理由/MVP 路径 |
| 免费托管（GitHub Pages） | AI + 用户 | 每个 HTML 一个可访问 URL；待仓库公开决定 |
| 报告尾部信任钩子 | AI | 1 个开放问题，非付费 CTA |

**产出**：可分发的免费报告链接 = 阶段 2 的弹药。

### 3.3 阶段 2 · 免费分发，换信任与线索（当前 ◐ 65%）

**渠道优先级**：
1. **B站**（独立开发者/微创业者；专栏 + 动态 + 评论区）

4. **V2EX / 即刻 / 小红书**（待用户登录；V2EX 优先「程序员/分享创造」）
5. **GitHub README**（长期 SEO；待仓库公开）

| 动作 | Owner | 验收 |

## 4. 定价与成交纪律

### 4.1 价格口径

- **唯一价格表**：`docs/PRICING-VALIDATION.md` §3。
- 对外统一：**首单 ¥199（限前 3 单）**；深度版 ¥499；白标 ¥999–2999 起。
- 定价文档保留 3–5 单弹性；**对外话术统一按「前 3 单」**，避免解释成本。
- 未达校准/风控解锁前，**不做任何公开发布报价承诺**；私信报价允许。

### 4.2 报价前置条件（缺一不可）

1. 对方主动私信/评论，且已给出具体方向。
2. 已发免费样本/报告，对方看过。
3. 已完成免费探测，确认样本 ≥10 条、有 3 条可执行信号。
4. 对方主动问「完整版怎么弄 / 多少钱」。

### 4.3 成交后

1. 收关键词 → 当天确认能做/不能做。
2. 跑管线 + 人工复核 → 3–5 天交付 HTML + Markdown。
3. 交付时问：愿不愿做匿名案例（换验证价的条件）。
4. 记 ledger（金额）+ journal（真实数字）+ `content.csv`（来源内容）。

### 4.4 定价实验规则

- 每 5 单复盘：成交价 vs 报价、还价幅度、流失原因。
- ≥3 单「嫌贵流失」→ 降档或拆小权益；连续 3 单不还价 → 试探上探 ¥399/¥599。
- 调整需在 CHARTER §4 记录理由；禁止编造成交数据。

## 5. 转化 SOP（从曝光到交付）

### 5.1 第一步：评论区/私信第一句

**原则**：先给价值，不急着报价；只回主动来的人，不群发、不主动私信陌生人。

| 场景 | 回法 |
|---|---|
| 认可/感谢 | 谢谢。你也在做类似的方向吗？有具体场景可以说说，我帮你看看那个方向的评论数据够不够。 |
| 求报告/链接/清单 | 报告和打标清单都整理成 PDF 了，私信我发你（正文不方便放链接）。 |
| 质疑数据/样本 | 你说得对，样本确实偏：单平台、校准 8/20、top3 66.7% 没到 70% 线——所以我只把它当线索，不当结论。你提的这个情况我记下了，下一轮补进去。 |
| 问方法细节 | 给 1–2 条能立刻用的操作，其余留到私信。 |
| 抬杠/嘲讽 | 不回；或一句「有道理，我按你这个角度再想想」。不辩论、不阴阳。 |
| 广告/引流 | 不回复、不删除（除非明显违规），忽略。 |
| 公开问价格 | 这个私信聊，先看看你方向的数据够不够，不够我不接。 |
| 同行/合作 | 可以，私信聊。 |

### 5.2 第二步：私信 3 步转化

**第 1 步：发资料 + 筛方向**

> 报告发你了（附件）。想先问一句：你手上有没有一个正在纠结的方向？一句话就行——我帮你看看那个方向的公开评论数据够不够，不够我直说。

**第 2 步：免费数据探测（10 分钟，只给原话）**

有数据：
> 你这个方向我扫了一下：X 条评论里有 Y 条在求助/抱怨，比如这两条原话：
> 「……」
> 「……」
> 样本够不够做一份完整报告，我可以直说。

没数据：
> 这个方向公开评论太少（不到 10 条），挖不出可信结论，我不硬做。建议换个更垂直的词，比如「XX」，我再帮你看。

**第 3 步：报价（只有对方主动问完整版/多少钱时才发）**

> 完整的证据报告：你给关键词，我跑管线 + 人工复核，3–5 天交付。
> 含：信号分布 + 付费意愿（WTP）+ 替代方案缺口 + 7 天验证 SOP；每条结论都挂原始评论原话。
> 价格 ¥199（前 3 单验证价）；深度版 ¥499（加可部署测试落地页 + 7 天答疑）。
> 接单前我会先评估你这个方向能不能做——做不了直接说，不收钱。
> 另外：报告里少于 3 条可执行信号，全额退款；先发你一份样例（脱敏），看完再决定。

### 5.3 常见异议

| 对方说 | 回法 |
|---|---|
| 能保证赚钱吗？ | 不能。保证的是证据真实、可核对、判断有依据；赚不赚钱取决于执行。 |
| 太贵了 | 你自己扫 200 条评论加整理，大概两周；这单 3–5 天。觉得不值就不拍，免费样本先用着。 |
| 再想想 | 可以。样本留着，方向想清楚再来。 |
| 能便宜点吗 | 验证价已经是底线（含匿名案例授权），不议价。 |
| 能退款吗 | 能：报告里少于 3 条可执行信号，全额退款。 |
| 数据靠谱吗 | 公开评论、匿名化、每条可回溯；我的校准只到 8/20、top3 66.7%，没到 70% 线——所以我只给线索，不打包票。 |

### 5.4 必须叫用户的情况

- 退款、投诉、法律、隐私删除请求
- 开发票 / 对公转账 / 白标合同
- 平台警告、限流、封禁通知
- 任何需要动账号设置的操作（登录、绑定、实名、收款）
- 报价被要求打折到 ¥199 以下，或对方要求承诺收益

## 6. 内容与分发 SOP

### 6.1 每日 60 分钟（可持续版）

| 时间 | 动作 | 产出 |
|---|---|---|
| 5 min | 看昨天数据：评论/私信/收藏/主页访问 | 判断今天要不要调整 |
| 10 min | 选角度（按排期，允许按热点调整） | 1 个角度 + 1 个真实数据 |
| 15 min | 写微内容（50–150 字） | 1 条动态/想法 |
| 15 min | **分发**：2–3 条真实评论（无链接、无品牌） | 目标人群触达 |
| 5 min | 合规自检 10 条 | 过检才发 |
| 5 min | 发布 + 记 `content.csv` | 链接、初始数据 |
| 5 min | 回评论/私信 | 按回复手册 |

**原则**：宁可少发，不发没信息量的内容；**分发优先于发稿**。

### 6.2 每周节奏

| 类型 | 频率 | 长度 | 说明 |
|---|---|---|---|
| 微内容（动态/想法） | 每天 1–2 条 | 50–150 字 | 同一平台每天最多 1 条 |
| 长内容（专栏/回答/文章） | 每周 3 条 | 600–1500 字 | 1 长 → 拆 5 微 |
| 真实评论分发 | 每天 2–3 条 | 20–100 字 | 只回真实问题，不刷量 |
| 复盘 | 每周日 | — | 5 问 + 下周排期 |

### 6.3 内容生产 SOP（1 长 → 5 微）

1. **长内容**：一个角度 + 一个真实数据 + 2–3 条原话 + 一个可执行动作。
2. **拆微内容**：金句 / 数据点 / 原话 / 反常识 / 提问，各 1 条。
3. **改平台语气**：B站偏「复盘」、知乎偏「论证」、小红书偏「清单」、爱发电偏「日记」。
4. **合规自检**：零链接、零价格、无「保证/稳赚/必爆」、无编造案例。
5. **发布 + 记录**：链接、初始数据、24h 数据。

### 6.4 平台规则（发布前逐条复核）

| 平台 | 外链 | 承接 | 额外注意 |
|---|---|---|---|
| B站专栏/动态 | 正文不放 | 私信/评论区 | 不提「爬虫/抓取/风控」；不贬低其他 UP；分区选对 |
| 知乎回答/文章 | 正文零链接 | 私信 | 回答必须与问题强相关；AI 辅助必须勾选声明；回答不做带 CTA 的转化稿 |
| 爱发电动态 | 不放第三方链接 | 站内私信 | 动态不写外部联系方式 |
| V2EX | 按版规 | 站内回复 | 不发广告；先参与讨论再发自己的东西 |
| GitHub README | 无限制 | README 链接 | 不放用户隐私/密钥 |

### 6.5 CTA 频率（硬约束）

- 同一账号：**7 天内最多 1 条带 CTA 的内容**。
- 其余日子只发纯价值（方法/数据/原话/提问），承接只放评论区，不主动导私信。
- 当前：Day 1（10-21）三平台 CTA 额度已用完；**10-22～10-27 B站/知乎只发纯价值、0 CTA**；10-28 恢复。
- 爱发电是自有阵地，可保留轻 CTA，但不刷屏。

### 6.6 角度库（轮换用）

反常识 / 数据拆解 / 失败复盘 / 自测清单 / 评论区考古 / 对比实验 / 用户原话 / 方法论 / 行业观察 / 争议观点 / 工具测评 / 现场演示 / 算账 / 故事 / 周复盘。

**轮换规则**：同一角度 7 天内不重复；同一平台每天最多 1 条；同一组数据 3 天内不重复使用。

## 7. 渠道策略与止损

### 7.1 渠道优先级

| 优先级 | 渠道 | 状态 | 说明 |
|---|---|---|---|
| 1 | B站 | ⛔ 登录丢失，暂停 | 专栏已发；评论区是当前最直接的分发动作；等用户重登 |
| 2 | 知乎 | ◐ 可登录，回答折叠 | 优先发文章/想法；回答只做纯价值、短、第一人称；AI 声明 |
| 3 | 爱发电 | ◐ 可登录，认证中 | 自有阵地；32 次/16 人；0 评论；不能当增长渠道 |
| 4 | V2EX | ⏳ 待登录 | 技术人群匹配；优先「程序员/分享创造」；草稿已备 |
| 5 | 即刻/小红书 | ⏳ 待登录 | 备选；需用户扫码 |
| 6 | GitHub README | ⏳ 待公开决定 | 长期 SEO；不依赖平台推荐 |

### 7.2 止损规则

- **阶段 2**：7 天内总私信 <2 且总互动 <10 → 不加量，换渠道；不追加费用。
- **单渠道**：连续 2 周 0 互动 → 停更该渠道，保留账号，不删内容。
- **单角度**：连续 2 次 0 互动 → 停掉该角度。
- **账号**：平台警告/限流/封禁 → 立即停发，记录，叫用户；不换号硬发。
- **校准**：20 条后 top3 <70% → 停止售卖推进，先复盘。

### 7.3 平台事故处理

| 事件 | 动作 |
|---|---|
| 被限流 | 不立刻删帖重发；如需重发，间隔 ≥48h；自查敏感词，记录 journal |
| 被判广告 | 该平台停 2 周，只发纯干货恢复权重 |
| 被封 | 不换号硬发；记录原因，转其他渠道 |
| 登录态丢失 | 停止自动化，叫用户手动重登；检查验证/警告；恢复前只做只读巡检 |
| 内容被折叠 | 先改稿去 CTA/去 AI 腔 + 勾选 AI 声明；仍折叠则等 24h/申诉/放弃，由用户拍板 |

| 数据记录/复盘 | — | ✅ 负责 |
| 法律/发票/合同 | ✅ 必须叫用户 | ❌ 不自行承诺 |

## 10. 红线（任何平台不破例）

1. **公开区零明链**：不出现 URL、短链、二维码、微信号、QQ 群号、「加我/扫码」。
2. **公开区零价格**：不出现 ¥、价格、「付费/购买/下单/接单/私信报价」。
3. **零诱导**：不写「关注领取/点赞解锁/转发抽奖」；不承诺收益。
4. **不编造**：不编客户、收入、案例、市场规模、用户数；数字必须能回溯。
5. **不假装用户**：不用小号刷评论、不冒充客户、不群发私信。
6. **不贬低竞品/其他创作者**。
7. **AI 辅助必须按平台要求标注**；知乎必须勾选「包含 AI 辅助创作 作者对内容负责」。
8. **平台规则优先**：发布前逐条复核当时规则；不确定就不发。
9. **账号安全优先**：登录/绑定/实名/收款由用户操作；AI 只操作已登录浏览器。
10. **不绕过风控**：平台 IP 级风控不绕；等冷却/换出口/原机重试。
